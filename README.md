# My Agent Skills Library

A personal collection of AI agent skills for software development, SaaS architecture, SEO, WordPress, and AI video production.

## Supported Agents

- Claude Code
- OpenCode

## Skills

| Skill | Description |
|---|---|
| saas-development | SaaS architecture and full-stack development |
| nextjs-expert | Next.js and React development |
| database-expert | Neon and PostgreSQL |
| vercel-deployment | Vercel deployment and configuration |
| seo-optimization | Technical SEO |
| wordpress-expert | WordPress and WooCommerce |
| ai-video-production | AI video workflows and prompt engineering |

## Installation

Install all skills from this repository:

```bash
npx skills add 68244364/my-agent-skills
```

Install a specific skill:

```bash
npx skills add 68244364/my-agent-skills --skill saas-development
```

## Updates

```bash
npx skills check
npx skills update
```
